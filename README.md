# Домашнее задание к блоку «Жизненный цикл и работа с HTTP» — Задача «Мировые часы»

Веб-приложение на React 19 и TypeScript 5 для отображения и управления мировыми часами в различных часовых поясах. Проект реализует синхронизированные аналоговые часы с продвинутой оптимизацией рендеринга и полным контролем утечек памяти при размонтировании компонентов.

## 🚀 Функциональность и архитектурные решения

Приложение спроектировано с учетом жестких требований к производительности и безопасности потоков данных:

1. **Атомарная инкапсуляция состояния (Оптимизация рендеринга):** Логика таймера (`setInterval`) и состояние времени (`useState`) полностью вынесены в изолированный дочерний компонент `<ClockHands />`. Это гарантирует, что каждую секунду в Virtual DOM обновляются только три линии стрелок, в то время как родительский компонент `<WorldClock />`, кнопки удаления и 12 чисел циферблата остаются статичными и не подвергаются ре-рендерингу.
2. **Абсолютная синхронизация секунд:** Для устранения визуального рассинхронизма между разными часами (эффект задержки при добавлении) внедрен расчет минорного смещения системы (`1000 - new Date().getMilliseconds()`). Первичный `setTimeout` выравнивает запуск интервала точно по границе следующей секунды операционной системы, заставляя все секундные стрелки двигаться в унисон.
3. **Безопасное управление ресурсами (Cleanup):** Возвращаемая функция очистки внутри `useEffect` гарантирует вызов `clearInterval` и `clearTimeout` в момент удаления карточки пользователем или размонтирования приложения, что полностью исключает утечки памяти (*memory leaks*).
4. **Тригонометрическая разметка:** Расчет позиций для 12 чисел циферблата вычисляется автоматически на основе математических формул синуса и косинуса. Вычисления вынесены за пределы компонента в кэш-константу `CLOCK_HOURS`, предотвращая трату тактов CPU.
5. **Современная типизация (React 19):** Обработка формы переведена на современный стандарт `SyntheticEvent<HTMLFormElement>` в связи с депрекацией (`@deprecated`) типа `FormEvent` в актуальных версиях определений типов React.

## 🛠️ Технологический стек

* **Frontend:** React 19 (Функциональные компоненты, Хуки эффектов и очистки)
* **Язык:** TypeScript 5+ (Строгая типизация синтетических событий и ригонометрических моделей)
* **Сборщик:** Vite 8
* **CI/CD:** GitHub Actions (автоматический деплой сборки из папки `dist` на ветку `gh-pages`)

## 🔧 Локальное развертывание, установка и запуск

Для запуска проекта на локальном компьютере выполните следующие шаги:

1. **Установите зависимости проекта:**
   При установке используется флаг для корректного разрешения зависимостей в среде React 19:

    ```bash
    npm install --legacy-peer-deps
    ```

2. **Запустите сервер для разработки (локально):**

    ```bash
    npm run dev
    ```

3. **Откройте приложение в браузеры:**
   После запуска терминал предоставит локальный адрес. Обычно это:
   [http://localhost:5173](http://localhost:5173)

4. **Сборка проекта (Production build):**
   Для генерации оптимизированного статического пакета выполните:

   ```bash
   npm run build
   ```
